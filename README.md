# かぞへ

小学1〜6年の「数と計算」を中心に、自分のペースで練習する **かぞへ v0.2.1**。初期画面の入力欄周辺の余白を直した、v0.2の不具合修正版です。正式リリースはまだ行っていません。

かぞへ（Kazohe）は[SAIEL](https://sites.google.com/shimane-edu.org/saiel/%E3%83%9B%E3%83%BC%E3%83%A0)が制作・開発しています。

## 使い方

[Kazohe.html](Kazohe.html) を保存し、ブラウザで直接開いてください。この1ファイルで動きます。インストール、サーバー、ネット接続、外部ライブラリは不要です。

- 全101チャレンジ。学年・分野・例題を見て1つ選べます。「いくつか・ほかのがくねんも えらぶ」を開くと、複数を組み合わせられます。選んだ内容と開始ボタンは画面下に表示します。
- 練習10・20・30問／無制限と、チャレンジに応じたタイムアタック。
- 多桁の整数、小数、分数、商と余り、通分、約数集合などの入力。
- 2回の誤答で次の一手のヒント。「こまったら助けて」で完成解答・筆算を確認できます。
- 分数は上下の表記。筆算は位の破線と日本の割り算記号を使い、数字と説明を別の欄に配置します。小さい画面で桁数が多い場合は、説明欄全体を筆算の後へ移します。
- 分数・通分・商と余りでは、入力中の欄を表示し「つぎの らんへ」で移れます。画面キーは文字の選択・カーソル位置にも対応します。
- Score、コンボ、条件と支援の有無ごとの自己ベスト。結果の詳細と、任意で選べるおすすめ。
- 練習の途中再開、JSONバックアップ、音・演出の切替、キーボード操作、動き軽減への対応。

学習指導要領の内容を参考にしています。チャレンジへの分割、点数、出題範囲、おすすめの判定は本アプリ独自の設計で、能力を診断する検査ではありません。

## 記録について

1人1端末を想定しています。名前は任意です。ブラウザや `file://` の保存制限により、記録が保持されない場合があります。その場合は画面に通知し、学習を続けられます。ファイルを移動する前や別のブラウザへ移る前には、設定からJSONを書き出してください。

JSONの読込みは、同じv0.2系列（v0.2.1を含む）の記録による完全置換です。v0.1の記録は自動移行せず、旧保存キーを削除・上書きしません。旧版のJSONは未対応版として拒否します。タイムアタックは再読込みで破棄され、練習は最後の問題完了境界から再開します。

## 開発と検証

Node.js 24を使用します。以下は開発者向けの手順です。利用者が実行する必要はありません。

```sh
npm ci
npm run build
npm run build:check
npm run lint
npm run audit:catalog
npm run test:unit
npm run test:property
npm run test:pedagogy
npm run audit:single-html
npx playwright install --with-deps chromium firefox webkit
npm run test:e2e
npm run audit:visual-diff
npm run audit:release -- --machine-only
```

`src/` の教材・数値処理・画面・スタイルを結合して、`Kazohe.html` を生成します。テストは生成後のHTML内の実コードを読み、別の整数・有理数オラクルと固定例で検証します。標準の生成検証は101,000問、教材説明検証は別に4,040問。ブラウザ検証は3エンジンで `file://` と外部通信遮断を使用し、全技能・生成分岐・4画面幅・全9入力形式を確認します。HTMLだけを一時フォルダへ移した動作も検査します。

画像比較は新Public内の別commitにあるHTMLと候補を同じブラウザで撮影します。PRではbase、pushでは更新前のcommitを基点にします。別の基点は環境変数 `VISUAL_BASE_REF` にcommitを指定できます。基点が取得できなければ失敗します。差分画像の生成成功は、見やすさの合格を意味しません。

結果は `reports/`、スクリーンショットは `reports/screens/`、画像比較は `reports/visual-diff/index.html` に生成します。レポートには対象HTMLのSHA-256が付きます。検証の対応と制限は [検証ガイド](docs/verification.md) を参照してください。旧環境の目視結果は新しい検証の合格として引き継ぎません。

通常の `npm run audit:release` は目視・実機の証跡も要求します。`--machine-only` の成功は自動検証済み候補であり、正式リリースの判定ではありません。GitHub Actionsはpush・pull_request・手動実行で起動し、数学・教材、3ブラウザの並列検査、画像比較、同じHTMLの証跡集約を行います。公開やマージは行いません。

このPublicリポジトリは、実装、テスト、GitHub Actions、公開リリースの作業場所として使用します。
