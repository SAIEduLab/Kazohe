For learners

こんな学び方に。

速さだけを競うのではなく、選ぶ・考える・確かめるを自分のペースで進められるようにしています。

1

学年と分野から選びたい

小学1〜6年の「数と計算」を中心に、学年・分野・例題を見ながら練習内容を選べます。

2

つまずいたら支えてほしい

誤答が続いたときのヒントや「こまったら助けて」で、次の一手や完成解答を確認できます。

3

あとから続きをやりたい

練習途中の再開、自己ベスト、JSONバックアップなど、続けるための記録機能を備えています。

Features

学ぶための機能を、まっすぐに。

練習・入力・支援・記録まで、児童が使う流れを一つのHTMLにまとめています。

101

101チャレンジ

整数、小数、分数、商と余り、通分、約数など、学年に応じた内容を選んで練習できます。

10

練習量を選べる

10・20・30問、無制限の練習に加え、チャレンジに応じたタイムアタックも用意しています。

?

ヒントと学習支援

2回の誤答で次の一手を示し、必要なら完成解答や筆算も確認できます。

Aa

入力をわかりやすく

分数、商と余り、複数欄の入力など、内容に合わせた入力欄と画面キーを使えます。

↺

記録・再開・バックアップ

Scoreや自己ベスト、途中再開に対応。設定からJSONを書き出して記録を保管できます。

⌨

いろいろな端末で

スマートフォン、タブレット、Chromebook/PCを想定し、タッチとキーボードの両方に対応しています。

How to use

使い方は、3ステップ。

練習したい内容を選ぶ

学年・分野・例題を見て1つ選ぶか、複数のチャレンジを組み合わせます。

自分のペースで解く

キーボードや画面キーで答えを入力。困ったときはヒントや支援を使えます。

結果を見て続ける

Scoreや詳細を確認し、必要ならおすすめを選んだり、あとで続きを再開したりできます。

Single HTML

アプリ本体は、Kazohe.html ひとつ。

「かぞへ」本体はCSS・JavaScript・問題生成・効果音・保存処理を1ファイルに含み、実行時にCDN、外部フォント、外部画像、外部APIを必要としません。ファイルとして保存し、ブラウザで直接開くこともできます。

  • 外部ライブラリ不要
  • サーバー必須ではない
  • タッチ / キーボード対応
  • 動き軽減にも配慮
